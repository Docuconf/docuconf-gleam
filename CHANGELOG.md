All notable changes to docuconf for Gleam are documented here. Entries after 0.1.0 are generated by
[release-please](https://github.com/googleapis/release-please) from Conventional Commit messages; see
[CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0

First version: typed configuration contracts for Gleam applications on the Erlang and JavaScript targets,
implementing spec `v1alpha1`.

### Features

* Typed builders, combined with `use` like decoders, that declare environment variables and file inputs with
  descriptions, secrets, constraints and list bounds (`itemMin`/`itemMax`).
* Boot validation of variables and files (config files, TLS key pairs, CA bundles, keystores) that reports every
  problem at once with stable error codes.
* Contract export to `contract.cue`, contract-first mode and the shared conformance runner.
* The `orders` example, a small wisp service.
